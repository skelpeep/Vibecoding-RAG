# 本地验收记录

此目录保存运行验证脚本产生的 JSON、终端输出和截图。原始记录包含本地路径、演示记录 ID、进程信息及存储拓扑，因此默认保留在本机，不随 Git 提交。

- 历史结果与八项需求映射见 [最终验收](../final-validation.md)。其中 `evidence/stage*/...` 表示本地证据路径，新克隆的仓库不包含这些原始文件。
- 可公开的界面预览单独放在 [docs/assets](../assets/)，内容来自虚构演示数据。
- `scripts/verify_*.py` 可用于重建相应检查。真实集成脚本需要配置存储、远程模型与本地初始化账号；部分脚本还依赖前置脚本生成的演示记录。
- 日常无外部依赖的后端回归使用 `uv run pytest -q`，前端检查使用 `npm --prefix frontend run build`。

不将账号密码、访问令牌或原始业务资料加入验收输出。需要分享特定记录时，先审阅内容并单独选择，不对整个目录强制 `git add -f`。
