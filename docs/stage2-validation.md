## 实施中修复

首次迁移发现两个版本唯一约束自动生成同名索引，修正为独立名称；仅对本轮已创建、经核验为空的表续建，模型与库完全一致后记录版本。未清空库或覆盖真实数据。

补充任务文件归属的 0002 迁移时，修正了 Alembic 自动生成的索引/外键执行顺序：先建立被引用复合唯一键，再替换外键。最终迁移文件已重新进行全新升级/降级验证。降级直接按依赖逆序删表，避免先删除被外键引用的索引。

## 实际边界

- 当前 API 在 Windows 本地运行，MySQL 使用已授权虚拟机的专用项目库。只更新本地开发服务，没有对外发布。
- 本轮没有旧知识映射或数据迁移，示例初始化只建立身份与组织。知识权限测试使用标明的测试记录，不创建伪造向量/模型结果。
- 归属 API 只提供文件/任务/批次/会话元数据。内容下载、历史、安全 RAG 上下文、SSE 任务执行、FAQ 多来源返回前校验需要阶段四至六接入。
- outbox_events 已写入授权变更事件，但尚无消费者和 Redis 缓存验证；权限引擎当前直接查询 MySQL。
- 原完整模型/PDF/视觉 RAG 仍未验收；本轮范围止于阶段二。旧数据路由主动封闭，保留 HTML 和原流程源码供后续接入。
- 没有进行压力或多 worker 争抢测试，持久化导入执行器尚未实现。现有测试覆盖数据库约束与请求权限边界。
- 唯一测试警告是 Starlette 对 httpx 测试客户端的弃用提示，测试均按实际结果报告。
