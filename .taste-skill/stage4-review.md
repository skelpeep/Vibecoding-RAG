# 阶段四应用界面评审

沿用 framed-sheet / seed 993422931；无重抽、无新增字体或主题。知识单元、版本、任务与组织授权均来自真实接口。图片仅展示本篇版本已关联并经鉴权取得的文件，不加载 Markdown 外链。样例只存在真实验收数据中，证据明确带 UI 验证标识。

## 工作与验证

- 四页面：知识列表、知识新建/编辑、详情（正文/附件/版本/访问范围）、导入中心。
- 图片：KnowledgeImage.vue，真实 Bearer 请求取得 blob URL，切换/失败/失权/卸载回收；15 秒重新校验。下载同样经 Bearer 代理取 blob，无 token 查询字符串或公开存储地址。
- 列表的编号、格式、范围摘要、分类、状态、创建者、更新日期在三种宽度均保留；手机主导航折叠，批次历史转为选择框以优先呈现逐文件任务。
- 编写草稿、访问范围都提供未保存离开确认。正文与版本读取失权清空；迟到的旧版本响应不能重新填回。
- 手工保存/编辑、附件上传、混合批次导入、版本激活与发布均为真实 API。模拟网络或权限响应的状态测试在 states.json 的 injected_state_checks 中单列，不能代替真实权限后端测试。

1. 导入中心最初历史批次堆叠在手机任务之前，改为原生批次下拉选择；任务阶段/总量字号提升至 13px。修正后 import inspect 0 FAIL / 0 WARN。
2. 列表补足稳定编号、格式与四维授权摘要；手机保留全部所需字段，宽度不溢出。list inspect 0 FAIL / 0 WARN。
3. 修正保存时未保存守卫把成功跳转挡住的问题；补充 FormData content-type、Blob 下载、异步失权防回填与标签长度校验。真实浏览器保存、批删、附件下载和重建交互通过。

## 七项看图结论

1. 首要问题：列表以知识身份与当前状态为主；编辑正文最大；详情将当前发布/激活/最新版本放在正文前；导入队列给出成功、处理中、失败与下一动作。每页主任务均能从首屏操作。
2. 网格：沿用同一 24px 桌面/16px 手机工作区边界。正文与 280px 资料栏共享上缘；表格和标题共享左右边界；信息侧栏不强行与正文等高。短文档右侧资料栏闭合余白。
3. 色彩：蓝灰纸夹品牌与青色状态进度延续前三阶段；主要操作近黑。无彩色卡片、渐变或装饰性指标；知识版本关系条代表真实状态。
4. 数字：列表总数由分页 API 返回；批次分项数量取真实 counts；进度显示实际 percent，未处理为 0；版本号、切片个数来自服务端。表格日期右对齐、数字 tabular-nums。
5. 零与缺失：0 篇/0%、0 失败显示真实零，未分类为明确文本，无创建者等缺失元数据为短横占位。默认无授权显示“未开放阅读”。
6. 标记：版本状态只在相应版本/任务行出现；当前版本为独立语义标签，百分比与进度条一致。没有需要猜测的图例或图表。
7. 手机：导航折叠；知识行完整保留身份、分类、创建者、日期与动作；编辑/资料/授权单栏；授权组可折叠；导入批次选择后直接显示文件任务。390px 实测无整页横向滚动。
