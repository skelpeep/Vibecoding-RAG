# 阶段五问答工作台

沿用 framed-sheet / seed 993422931，无重抽；已读取 design-taste-frontend SKILL.md 与完整 app-screens.md。白色工作页、蓝灰纸夹、IBM Plex Sans + Noto Sans SC 本地字体、现有色彩 token 和开放书页标识继续构成品牌。

数据清单：归属当前账号的会话、标题、创建/更新时间、逐轮问题和回答、流式请求 ID、终态、权限提示、当前有效的知识来源、版本和切片位置。会话数、来源数与时间来自真实 API，不填入示例会话或运营数字。

主问题是“我的问题有哪些可核对的知识依据”。主栏按问题→回答→来源阅读；侧栏回答“之前问过什么”，输入区始终可以提出下一个问题。特色元素是回答下的“知识来源”：真实来源序号、标题与位置，并且打开时重新校验当前授权。权限缺失提示直接放在对应回答。

桌面网格算式：工作页内部可用宽度 = 248px 会话栏 + 24px 间距 + 剩余问答栏，全部对齐工作页两边。768px 与390px 一次展示一个区域，选择会话进入详情，返回恢复列表滚动位置。

主操作发送问题用近黑色；来源操作用青色，生成状态、错误与权限提示使用语义颜色；不使用渐变、业务假数据、远程图片或登场动画。输入支持中文 IME、Enter 发送与 Shift+Enter 换行。停止、切换、离开都会取消服务器任务并关闭流，迟到事件不能写入另一会话。

空会话说明可提问的真实范围；未命中、权限不足、低置信度、停止、连接错误分别呈现可理解的文案。Markdown 通过 marked + DOMPurify 处理，不允许原始 HTML、图片、嵌入或危险链接。引用通过 AI 读者入口读取，不要求知识维护菜单。
