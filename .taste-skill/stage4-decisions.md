# 阶段四知识工作区

沿用 framed-sheet / seed 993422931，IBM Plex Sans + Noto Sans SC、蓝灰纸夹外框、开放书页品牌和现有 token。没有重抽。应用界面工作流程，新增控件无登场动画，反馈仅 hover/focus/disabled。

数据清单：知识单元稳定 ID、标题/摘要/正文、分类/标签、创建者、发布状态、当前与最新版本、原文/附件、四维授权、批次、逐文件任务、真实构建进度。所有数据及总量从真实 API 返回，无前端样例或假运营数字。

知识列表首先回答“哪些知识可阅读或由我维护”；主操作新建知识，导入中心次操作；分页/状态/分类/标题搜索与可删除项选择对应后端真实范围。

详情首先回答“当前发布了哪个版本”；正文在主栏，最新草稿维护与当前对外版本明确区分，版本/附件/访问范围分页工作。创建者维护能力不等于正文读者授权，默认无人可读，四维 OR 关系用文字与实际选中数量呈现。

编辑首先回答“本次提交的新版本是什么”；标题正文为主，分类标签摘要为辅。保存产生待构建版本，成功不自动激活。访问范围独立保存且有自己未保存提示。

导入中心首先回答“哪些文件处理成功，哪些需要重试”；上传区与批次历史、每文件阶段/百分比/错误/重试共用真实持久化任务。选中文件可移除，同名文件保留为不同知识，目录保留相对路径。

特色元素是“最新版本 → 已就绪 → 当前发布”的知识交付关系带，对应真实版本 ID 和状态；颜色只用于状态与进度。桌面正文网格为可用宽度 − 280px 信息栏 − 24px 间距；手机单栏，筛选折叠，表格按知识身份与状态组织成行。

验收由真实构建、浏览器交互和三宽度技能检查完成，结果补充到 stage4-review.md。
